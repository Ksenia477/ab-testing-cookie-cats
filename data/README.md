# Данные Cookie Cats

Локальный файл [cookie_cats.csv](cookie_cats.csv): 90 189 игроков, 5 столбцов.
Это публичный учебный набор с результатами A/B-теста, а не синтетическая генерация.

Происхождение — проект DataCamp «Mobile Games A/B Testing with Cookie Cats».
Описание эксперимента и полей доступно в
[карточке датасета](https://www.kaggle.com/datasets/mursideyarkin/mobile-games-ab-testing-cookie-cats).
Старая страница DataCamp /projects/184 теперь перенаправляет на другой проект;
прямая ссылка на архив ответила 403. Поэтому файл получен из
[публичного зеркала GitHub в фиксированном коммите](https://github.com/sevvalnrdede/AB-Test-Analysis-Mobile-Game-Gate-Placement/blob/ab9c6de8a38bb36fa6a155ca93bb07dab292c632/cookie_cats.csv).

Файл скачан 9 сентября 2026 года и сохранён без изменений.

| Поле | Описание |
|---|---|
| userid | Уникальный идентификатор игрока |
| version | gate_30 → control; gate_40 → treatment |
| sum_gamerounds | Число сыгранных раундов; карточка указывает первые 14 дней |
| retention_1 | Вернулся ли игрок на 1-й день после установки |
| retention_7 | Вернулся ли игрок на 7-й день после установки |

Новый столбец group создаётся в памяти при анализе. Строки не удаляются.
Отдельный «очищенный» CSV не нужен: исходная таблица проходит структурные проверки.
Это не означает, что дизайн и сбор данных полностью проверены.

В карточке описано случайное назначение, но плановые доли трафика,
даты и журналы событий отсутствуют. Предположение 50/50 используется только
для явно обозначенной диагностической проверки SRM.
