# A/B-тестирование: Cookie Cats

Небольшой учебный проект на Python: **EDA → H₀/H₁ → выбор теста → p-value →
доверительный интервал → вывод для бизнеса**.

Бизнес-вопрос: стоит ли переносить первый игровой барьер с 30-го на 40-й
уровень, чтобы улучшить возврат игроков на 7-й день?

Основной анализ — [Jupyter Notebook](ab_test_cookie_cats.ipynb).
Для чтения без Python откройте [готовый HTML-отчёт](reports/ab_test_report.html)
в браузере. Краткий результат — [вывод для бизнеса](reports/business_summary.md).

## Результат

| Показатель | Control: gate_30 | Treatment: gate_40 |
|---|---:|---:|
| Игроков | 44 700 | 45 489 |
| Вернулись на 7-й день | 8 502 | 8 279 |
| Удержание на 7-й день | 19,02% | 18,20% |

Наблюдаемая разница treatment − control: **−0,820 п.п.**, или **−4,31%**
относительно control. Номинальный двусторонний p-value: **0,001554**.
95%-й доверительный интервал Ньюкомба для разницы: **[−1,328; −0,312] п.п.**
При сопоставимой аудитории это около **82 потерянных возвратов на 10 000
установок**; интервал средней разницы — от 31 до 133 потерянных возвратов.

**Рекомендация: сохранить control и отложить внедрение treatment.**
При предположении планового распределения 50/50 найден сигнал несоответствия
размеров групп, SRM: p = 0,0086 при диагностическом пороге 0,01.
Сначала нужно проверить плановые доли и сбор данных. До этого тест и
доверительный интервал предварительные: наблюдаемое снижение нельзя уверенно
приписать переносу барьера. Плановые доли нельзя подбирать под полученные числа.

## Что входит в анализ

1. Описание задачи, единицы анализа и исходных данных.
2. Проверка пропусков, дубликатов, типов и допустимых значений.
3. EDA: численность групп, удержание, распределение активности и выбросы.
4. Проверка SRM с явным допущением 50/50.
5. H₀: p_treatment = p_control; H₁: p_treatment ≠ p_control; α = 0,05.
6. Двусторонний z-тест двух независимых долей и проверка его предпосылок.
7. 95%-й интервал разницы, абсолютный и относительный эффект.
8. Проверка расчётов через формулу z и эквивалентный χ²-тест.
9. Бизнес-рекомендация с ограничениями и переводом эффекта в игроков.

Основная метрика — retention_7. Retention_1 и количество раундов используются
для описания, без дополнительных проверок значимости. Все назначенные игроки
остаются в анализе: по активности после назначения выборка не фильтруется.

## Запуск

Данные уже лежат в проекте. Для повторных расчётов доступ в интернет не нужен.
Для первого установления библиотек он потребуется.

Используйте Python 3.9–3.12. Выполнение проверено на Python 3.9.6.
На этом компьютере локальное окружение .venv уже подготовлено.

Из корня проекта на macOS / Linux:

~~~bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run_analysis.py
~~~

На Windows вместо команды активации выше используйте:

~~~powershell
.venv\Scripts\Activate.ps1
~~~

Скрипт выполняет ноутбук с чистым ядром, сохраняет результаты в нём и обновляет
HTML, краткий отчёт, таблицу, JSON и графики. Ошибка в любой ячейке останавливает
выполнение. Глобальное ядро Jupyter устанавливать не требуется.

Для работы с кодом по ячейкам после активации окружения:

~~~bash
jupyter lab ab_test_cookie_cats.ipynb
~~~

В Jupyter выберите **Restart Kernel and Run All Cells**, чтобы пересчитать
весь анализ. HTML-версия содержит текст, таблицы и встроенные графики;
весь исходный код находится в ноутбуке.

## Данные и ограничения

Используется публичный учебный набор Cookie Cats из проекта DataCamp;
локальный CSV скачан из фиксированной копии на GitHub. Ссылки и контрольная
сумма приведены в [описании данных](data/README.md).

Это ретроспективный учебный анализ, а не заранее зарегистрированный эксперимент.
Нет дат, протокола, событий рандомизации, выручки и характеристик игроков до
эксперимента. Поэтому нельзя полностью проверить окно наблюдения и корректность
дизайна, оценить прибыль или обещать такой же эффект в другой аудитории.
